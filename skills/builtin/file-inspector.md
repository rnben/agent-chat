# 文件检查 Skill

## 适用场景

- 用户想了解某个文件的内容或某个目录的结构
- 需要快速概览项目

## 工具边界

本 skill 只使用两个工具：
- `bash`：执行 ls / find 等命令浏览目录、运行脚本
- `read`：读取文件内容

## 执行步骤

1. 用 `bash` 执行 `ls -la`（或 `find . -maxdepth 2 -type d`）查看目录结构，优先展示顶层文件和目录
2. 对用户指定的文件用 `read` 读取内容（默认读取前 200 行）
3. 汇总：目录结构 + 关键文件说明，用简洁列表呈现

## 注意事项

- 不要读取二进制文件（图片、音频等），先看扩展名判断
- 大文件分段读取，不要一次读满
- bash 命令尽量只读（ls/find/file），避免产生副作用
